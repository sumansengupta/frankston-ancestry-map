# Frankston Ancestry Explorer

An interactive, responsive map of selected ancestry responses across Frankston Statistical Area Level 1 (SA1) regions.

- **Data:** Australian Bureau of Statistics, 2021 Census General Community Profile, table G08
- **Basemap:** Esri World Street Map
- **Geography:** ASGS 2021 SA1 areas contained within Frankston LGA

[Open the interactive map](https://sumansengupta.github.io/frankston-ancestry-map/)

Ancestry is a multi-response Census question. A person may report up to two ancestries, so response counts do not equal persons.
